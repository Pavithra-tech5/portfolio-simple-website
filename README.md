# Personal Portfolio Website

A simple personal portfolio website built using HTML and CSS. The website consists of two main pages, Home and Contact, with a clean and user-friendly design.

## Technologies Used

* HTML5
* CSS3

## Pages

* **Home** – Introduction and basic portfolio information.
* **Contact** – Contact information and communication details.

## Features

* Clean and simple design
* Easy navigation between pages
* Responsive layout
* Separate HTML pages
* External CSS styling

## Purpose

This project was created to practice HTML and CSS fundamentals and to build a basic personal portfolio website.

## What I Learned

* Creating webpages using HTML
* Styling webpages using CSS
* Linking multiple HTML pages
* Creating navigation menus
* Using external CSS files
* Building a basic responsive layout
